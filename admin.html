Koneksi Database (cPanel MySQL)

Hubungkan ke MySQL agar pengaturan tersimpan di server dan sinkron di semua perangkat.

URL lengkap ke file api.php di hosting Anda.

Harus sama dengan nilai API_SECRET di config.php.

Panduan Setup Database cPanel:

  1. Edit config.php dengan kredensial database cPanel Anda.
  2. Upload semua file PHP ke folder website di cPanel (via File Manager / FTP).
  3. Buka https://domain.com/install.php di browser untuk membuat tabel.
  4. Isi URL API dan API Secret Key di atas, klik Test Koneksi.
  5. Klik Simpan Konfigurasi jika test berhasil.
  6. Hapus install.php dari server setelah selesai!
